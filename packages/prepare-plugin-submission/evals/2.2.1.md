# Submission Studio 2.2.1 design revision

This release updates the architecture, implementation plan, official source
registry and agent interaction guidance. It does not add executable adapters
or alter the Python/TypeScript runtime. The target runtime for the planned
pipeline is 2.3.0, subject to its explicit acceptance scenarios.

Validate JSON/YAML and local references in the complete package; run the
existing regression suite to check that the documentation additions preserve
the current runtime. Preserve identity, audience, icon, starter prompts and
dependencies. Save and read back the changed files through the existing private
plugin's update route.

Observed on 2026-10-16: all 38 existing Python tests passed, skill validation
passed, and the complete package check reported no findings. All JSON parsed;
the new registry contains 33 unique primary sources, including the three
conditional conversion pages and the two API guides. Manifest identity and
presentation were preserved, with only the version changed. Python/TypeScript
runtime files, existing tests and pinned dependencies are byte-identical to
2.2.0. TypeScript was not rebuilt for this documentation-only revision.

Do not count schema inspection as a native Q&A interaction test. Do not count
the live official-page retrieval for this design as an implemented automatic
synchronizer. The 2.2.0 runtime evidence remains historical evidence for that
runtime; no new host, portal, MCP or model behavior is claimed here.
