# Submission Studio 2.1.0 validation

Validated on 2026-10-16. This release implements preflight auditing and evidence
preparation. Portal upload, review submission, legal attestations and publication
remain external human handoffs. Unloaded templates are expected to be blank.

- Twenty Python tests passed: fifteen synthetic preflight/report tests and five
  existing workflow tests. Python compilation and skill validation passed.
- Both TypeScript sources passed syntax checks; the connector kit and generated
  starter built with the pinned dependencies. Two SDK sample cases passed with
  actual modern negotiation observed.
- The experimental mcpdo client help and agent guide were read. Actual connection
  testing was blocked by `listen EPERM` on its private daemon socket in this
  environment. This is unverified runtime coverage. A synthetic adapter regression
  confirms blocked connections report no observed live inventory.
- The broken ZIP produced its four expected errors. Desktop stdio passed only
  with the explicit desktop-only route and supplied synthetic confirmation.
  Review-prep retained five positive and three negative definitions plus its
  synthetic demo URL. All three audit-pack integrity checks passed. No fixture
  endpoint, target server, upload or publication was used for these audits.
- Ten native prompt/grader folders now match the ten scenario definitions. The
  full native LLM benchmark was not run. An independent agent exercised the
  fixture workflow; its findings and follow-up correction are retained.

The [2.0.1 self-audit](../self-audit/2.0.1/coverage-matrix.md) replaces eleven
