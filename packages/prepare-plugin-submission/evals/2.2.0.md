engine chooses one current action, while a file adapter persists state, creates
the archive/audit/copy fields, validates host captures and records external human
observations. Users answer normal questions; the agent maintains the records.

journey tests, and five existing workflow tests. The new tests exercise a full
synthetic remote journey across both hosts, desktop eligibility and conditional
review steps, concrete broken-package findings, deferred preparation, stale
evidence/revision rejection, pending review, mismatched release references,
source-change invalidation, evidence import/revalidation, audit-output imports and
portable export/restore. Simulations never establish actual publication.

kit TypeScript build passed. TypeScript sources, pinned dependencies, author,
identity, icon and the exact plugin-level starter prompts are preserved.
